{# Shared money / verdict display macros. Usage: {% from "_money_macros.html" import money, pace_pill, dti_badge %} ``money`` is the ONE currency formatter for templates (Gate B7): it renders negatives with the sign before the dollar symbol (-$1,234.56, not $-1,234.56) and replaces the per-template "{:,.2f}" duplication. The unary minus inside is display formatting (sign placement), not financial arithmetic -- the value itself is computed in the service. ``pace_pill`` and ``dti_badge`` centralize the verdict-chip mappings. ``pace`` and ``dti_label`` are computed domain strings from the savings services (calculate_trajectory / _get_dti_label), not reference-table ``.name`` columns, so literal comparison here is the sanctioned pattern (see dashboard_card_audit.md, card 6 note). #} {%- macro money(value, cents=true) -%} {%- set fmt = "{:,.2f}" if cents else "{:,.0f}" -%} {%- if value < 0 -%}-${{ fmt.format(-value) }}{%- else -%}${{ fmt.format(value) }}{%- endif -%} {%- endmacro -%} {%- macro retained_badge(retained_amount) -%} {#- The figure a tick WOULD book, drawn only where it is not already on screen (plan step X-au-c3, developer 2026-08-17). A row reverted out of the settled band KEEPS what it recorded and a re-settle honours it, so its PLAN is what the balance counts and this is what marking it paid will record -- two different numbers about one row. The route decides which rows have such a gap (``transaction_service.retained_settle_amounts_by_id`` answers ``none`` for every row that does not); this macro only draws it, so the rule has one statement in Python and no template restates it. It is a BADGE and not a second figure in the money slot on purpose: the amount beside it is what the projection is counting today, and replacing that with a figure no balance uses would make the cell disagree with the column it sits in. -#} {%- if retained_amount is not none -%} ↻ {{ money(retained_amount) }} {%- endif -%} {%- endmacro -%} {%- macro pace_pill(pace) -%} {%- if pace == 'behind' -%} Behind {%- elif pace == 'ahead' -%} Ahead {%- elif pace == 'on_track' -%} On track {%- endif -%} {%- endmacro -%} {%- macro dti_badge(dti_label) -%} {{ dti_label|title }} {%- endmacro -%}
